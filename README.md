## Features

- **3D WebGL Orbital Particle Torus** — Real-time particle simulation with cursor gravity and orbital rotation
- **Signature Typewriter Engine** — Character-by-character typing with gradient blinking caret
- **Cursor-Responsive Ambient Grid** — Dynamic dot matrix that illuminates around mouse coordinates
- **Infinite Tech Logo Ribbon** — Draggable, auto-scrolling parabolic arch of technology badges with official brand logos
- **Interactive CLI Terminal** — Runnable browser terminal (`whoami`, `skills`, `projects`, `cat resume.md`)
- **Project Slider with Modals** — Horizontal swipeable cards with follow-cursor magnetic pills
- **Morphing 3D Particle Canvas** — Dual-section particle effects (curly brackets / circle constellation)
- **Peer Testimonials Marquee** — Auto-scrolling, draggable endorsement ribbon
- **Gravity-Defying Footer** — Hover-reactive letter physics with lift and rotation
- **Web Audio Synthesizer** — Zero-dependency tactile sound effects
- **Apple-Style Profile Zoom** — Instagram Story-style avatar expansion animation
- **Acumen-Style Header** — Slide-up roll-from-under navigation hover effects
- **Scroll-Aware Header** — Auto-hides on scroll down, reappears on scroll up
- **Light / Dark Mode** — Default light mode with persistent user preference

## Run Locally

```bash
# Clone the repo
git clone https://github.com/Tuborrr-Dev/israel-adetubo-portfolio.git
cd israel-adetubo-portfolio

# Install dependencies
npm install

# Start the dev server
npm run dev

# Open http://localhost:3000 in your browser
```

---

## Build for Production

```bash
npm run build
```

The static output will be in the `dist/` folder, ready for deployment on Vercel, Netlify, or Railway.

---

## Deployment

This project is optimized for **Vercel** (zero-config Vite support). Simply import your GitHub repo at [vercel.com](https://vercel.com) and deploy.
